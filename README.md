# Neutron local developer tools

Standalone source export of the local Windows/Java 8 offline development harness.
No game JAR, Minecraft/OptiFine sources, assets, natives, account data or old
repository history are included. This is not an installable Minecraft client
or an authenticated multiplayer launcher. The helpers require a separately
provided and reviewed local client checkout and legitimate local runtime inputs.

See tools/neutron-private-playtest/DEV-START.md for the actual launch contract.
The separate full client repository has not received distribution clearance.
