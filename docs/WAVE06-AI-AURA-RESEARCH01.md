## Verified data/model semantics

- `AuraFeatures.WIDTH=40`, `HISTORY=4`, hence **160 input floats**; ten outputs carry yaw and pitch mouse counts, click intent/interval, initial rotation/click reaction, normalized target body point (3 axes) and button hold. Neutron shall initially consume **rotation-only** outputs and must **not** adopt independent click-intent, interval, first-click timer or button-hold emission.
- `AuraNetwork`: 160→32→24→10 = **6,194 weights** = 24,776 raw float bytes (before arrays, statistics, optimizer or JSON). Forward path has tanh hidden layers, selected sigmoid heads; training has masked losses, mini-batches of 64, fixed RNG seed, gradient clipping/Adam-like moments, 60-epoch / 10,000-window upper bounds in the caller, best validation checkpoint and early stop after 10 stale epochs (after epoch 20). Model architecture does **not** establish motion quality.
- `AuraDataset` caps in-memory rows at **60,000** and validates gzip header/magic/version/dimensions, 0–60,000 row count, finite feature/label values and bounded metadata. `ready()` requires **≥600 frames**, **≥15 physical clicks**, ≥3 aim and ≥3 first-click reactions, ≥10 repeat intervals/releases, ≥20 crosshair aim frames, and ≥20 frames in each of 3 reach bands. The chronological validation holdout aims for ~20% with an 8-frame history gap; failures of reach/label coverage block training.
- `TrainedAura` is an **individual** calibrated checkpoint with nine buckets, sigma/correlation, timing range, loss and max-count checks; `valid()` requires finite dimensions/statistics, ≥600 records, ≥15 clicks, ≥3 reactions and ≥1 training epoch. `AuraLearning` loads `model.json` with a **2,000,000-byte** file cap and checks weight length and model validity. **No valid bundled model or transferable user weights were evidenced** from the audited package; a new client must not use random initialized weights as a playable model.
- `AuraBrain` takes physical integer mouse counts, bounded carry and camera pitch feedback. It also implements click burst scheduling (up to 8 caught-up iterations), which is **not** acceptable as a second Neutron attack scheduler. Target acquisition uses Vibe's numeric target ID and reset; Neutron must instead bind new identity tokens to actual entity + world + connection + owner + motion sequence to avoid ID reuse/stale target actions.

## Privacy and trust matrix — must be solved before any recording feature

| Material / trust boundary | Observed Vibe contract | Required independent Neutron gate |
|---|---|---|
| Manual processed rows | `<Minecraft data dir>/vibe/aiaura/demonstrations.bin.gz`, versioned gzip, 60k max | Local opt-in only, private path, strict bounded input and byte count, no upload or repo files |
| Raw manual events | `session-<timestamp>-<part>.events.gz`, relative nanoseconds, key/mouse code, pressed state, motion/wheel; parts rotate after 1,000,000 events | Treat as personal behavioral data; off by default, exclude chat/login/screens, bounded disk/retention, explicit preview/delete |
| Checkpoint | `model.json`, JSON weights and calibration, atomic temp rename | New versioned/checksummed own schema; max length, exact dimensions, finite weights, limit timing heads, reject symlinks/path traversal/oversized or corrupt files |
| Trainer thread | One cancelable background executor, generation token, atomic publish | Strict separation from game/GL threads, bounded queue/RAM/CPU/duration, interrupt/join semantics, avoid live-session model mutation |
| Target/account/world | Vibe numeric target ID and model scoped by module instance | Reject stale target/world/reconnect/suspension/account/focus; new acquisition token; no cross-account auto reuse |
| Telemetry / network | No uploader in the audited 13 classes; upstream describes local storage | Audit entire future Neutron call graph for unintended network, disable collection entirely by default; cannot infer client-wide telemetry absence |
| Data deletion / consent | Reset deletes dataset/model/session raw-event files in Vibe | Explicit user approval, preview list, narrow safe delete, Stop/Delete separate controls; don't touch unrelated local files |

**Rights gate:** Vibe and Neutron have GPL-3.0 repository licenses, but a repository license alone is not an audit of authorship for all helpers, weights and assets. Vibe documents unlicensed privately decompiled Gothaj Scaffold material elsewhere; none of it is eligible for reuse. Vibe's thirteen files are **RESEARCH_ONLY** at this gate; no classes, checkpoint, weights, shaders, arena assets or training data imported. Direct copying needs a separate provenance, dependencies and distribution-notice review (including overall client dependency compatibility). Independently specified algorithms and tests are the only planned implementation route.

## Proposed staged architecture (separate Draft PRs, never all at once)

**AI-AURA-CORE02 (after this report is reviewed):** Appended Aura-only `Rot Mode = AI Learned` after Adaptive, default remains Basic; no AimAssist/Scaffold mode migration. Introduce own Java-8 `NeutronAiModel` validator and deterministic pure inference with a deliberately smaller **rotation-only** output surface; exact schema/version specified and frozen before any model is generated. A valid *user-provided* local model is mandatory. Missing/invalid model returns **HOLD/inactive** and must grant no new C03 acceptance, C02 action or other automated operation. The output is a bounded rotation candidate passed to existing `RotationManager` quantization, priority arbitration, scene/connection and AttackScheduler gates. Do **not** port Vibe's click/due/poll or fake MoveFix owner. Reuse Neutron's real attack policy only when independent local acceptance and existing Aura eligibility hold. Apply fail-closed limits to all non-finite features, dimensions, confidence and dead/replaced targets.

**AI-AURA-DATA03 (independent subsequent PR):** explicit opt-in local manual recording in a separate training/practice surface, fixed data contract and optional local statistics. No live chat/credentials/world/account capture. Add start/pause/stop/delete, no silent background recording, no bundled sessions. This step requires VIS review for UI but no edits to their files in advance.

**AI-AURA-TRAIN04 (independent subsequent PR):** Java-8-only offline bounded worker with fixed-seed training, chronological session split + gap, masked targets, provenance/config checks, atomic validated checkpoint publication, cancellation and deletion tests. Prevent model self-training using generated actions. Full-run profiler must establish CPU/heap budgets. Live model replacement requires a fresh acquisition generation, not an in-flight pose.

## Test matrix and evidence bar

1. **Model/parser:** bytesize cap, wrong version/shape, NaN/Infinity, finite weights, malformed/truncated gzip/JSON, malicious huge arrays, symlink/path escape, corrupted hash, no checkpoint and wrong account; all inactive and no network/action.
2. **Feature & inference:** fixed 160 input and own documented outputs, numerical determinism for frozen seeds, controlled response to target wrap/pitch, time/FPS invariance at 20/60/144/240, monotonic Jerk/speed caps, fallback HOLD. Equality only expected within stated Java 8 float tolerance.
3. **Training (later):** ≥600 frames plus all label/coverage gates, missing/repeated session labels, no train/validation time leakage, fixed-seed reproducibility, held-out loss baseline, cancel mid-epoch, excessive dataset/memory/disk, partial write and atomic rollback. No "accuracy" marketing from training loss alone.
4. **Real Aura/hooks:** accepted C03 vs rejected/superseded, C02 unchanged, MoveFix ownership, target and world/connection/account switch, GUI/focus/disable/suspension, late duplicate events and input abort. Verify no action at zero/invalid model. A user-selected AI mode with no model does **not** silently activate Adaptive/Arsenic.
5. **Budget targets (not measurements):** target p95 inference ≤1 ms per client motion on the stated Java 8 host and no allocation proportional to recording length; bounded model weight count (6,194 is upstream only), e.g. ≤64 MiB incremental dataset footprint in a 60k-row stress fixture and isolated trainer capacity. Validate via actual heap/CPU evidence; until then `UNMEASURED`.
6. **Runtime:** Java 8 Maven CI and old golden tests, native OpenGL context, official launcher, offline/online worlds, real moving targets, concurrent modules, actual server version/config logs. Live anti-cheat compatibility, unflagability and human indistinguishability: **NOT CLAIMED**.

**Review gate:** AI-AURA-CORE02 is **BLOCKED_FOR_REVIEW** until the 13-class report, rights/provenance, intended model schema and privacy safeguards are accepted. No training, AI packet action, auto-import or release in this Research PR.
