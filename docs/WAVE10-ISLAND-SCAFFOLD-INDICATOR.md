# WAVE10 — Observed Scaffold Island status indicator

This small delta adds the previously missing separate status indicator. It reads the already copied `IslandStateMachine.Scaffold.status` produced by `IslandObservations`; it never invokes Scaffold planning, aiming, slot selection, placement, input, or network actions. Existing module values, legacy Island choices, state priorities, provider TTLs, fixture APIs, item IDs/metadata, block counts, and approach/profile text remain intact.

`IslandScaffoldIndicator.capture` recognizes only the six existing observed producer statuses. Searching uses a moving search arc, Aligning uses contracting brackets, Ready uses a check, Placing uses a small block glyph, Edge Guard uses a shield/stop mark, and Recovering uses a bounded return arrow. Short labels preserve that meaning. Warning colors identify Guard/Recovering; no glyph manufactures a confirmed Ready, a count, or a completion percentage. Unknown, absent, or legacy fixture statuses do not create an indicator.

The real copied status, sequence, glyph segments, and opacity are frozen before the deferred surface callback. Animation samples the existing `UiEffects.time()` and current Animations/Reduced Motion policy. Reduced or disabled motion produces identical static geometry and opacity for every timestamp. No additional scheduler, timer, state queue, effect framebuffer, shader, or asset is added.

The observed Scaffold view uses a complete 248 × 44 logical canvas with the original display-only item at the left, the existing known count/profile/status text in the center, and a 24-pixel status glyph in the previously reserved right region. The complete canvas fits uniformly inside the actual current Island morph frame, down to the smallest viewport; item, text and glyph do not acquire separate unbounded offsets. The glyph contains at most 14 line segments, and its OpenGL state is scoped and restored. The existing outer Island clip, world/player/epoch fence, and withdrawal of stale producer views remain in force.

Six new `IslandScaffoldIndicatorTest` methods cover actual DTO/adapter status mapping, unknown/legacy exclusion, distinct animated states, static Reduced Motion/off behavior, bounded glyph segments, one-pixel/morph composition fitting, read-only repeated captures, and expired source withdrawal. Local standalone checks compile the actual new model against existing actual pure Island classes with OpenJDK 21 `-source 8 -target 8`; this is not a Java 8 runtime or JUnit substitute. Exact local assertion output is recorded with the patch manifest.

Full Java 8 Maven/JUnit for this delta and native screenshots are **NOT_RUN** until their own gates. The preceding PR155 Notices/font revision has a separate green Java8 run; that result does not validate this new renderer. Native captures still need actual Searching/Aligning/Ready/Placing/Edge Guard/Recovering producer states, valid/unknown items, small and large UI scales, transitions to higher-priority Island content, Reduced Motion, GL state restoration, and frame-time measurements. Pure geometry does not establish native appearance.
