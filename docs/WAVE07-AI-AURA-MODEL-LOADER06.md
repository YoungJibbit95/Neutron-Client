## Local installation and explicit consent

- The sole model input is a `NeutronAiTrainer.Result` with `Status.CANDIDATE`, locally produced from NMD4 manual data. The loader rechecks the actual checkpoint's NAI1 fixed schema, samples, epochs, validation metrics, serialized length/digest and the result's metrics.
- **Saving** a candidate is an explicit separately authorized operation. **Loading** an already saved model requires a *second explicit user action* plus a fresh per-session consent flag; never on startup or by scanning unknown files. The flag is RAM-only and never saved in a config.
- Fixed files only under `<trusted Minecraft data>/neutron-ai/personal-v1/`: `model-v1.nai`, `origin-v1.bin`, `local-key-v1.bin`, with temporary fixed staging files. Exact lengths, no symlink traversal, strict existing NAI1 digest, local HMAC-SHA256 manifest and provenance metadata validation. Unknown filenames never enter a loader API.
- The manifest records only fixed schema/protocol, counted physical events/epochs, validation baseline/loss and SHA256 of the model; **not** names, UUIDs, chats, server addresses, login tokens, credentials, profile fields, coordinates or target IDs. An integrity MAC backed by a key stored in the same local directory detects ordinary modification; it does **not** defend against someone with file-system control who can rewrite both the model and key. It also does **not prove real human label provenance**, which requires the separately audited T2 physical-input/consent adapter and privacy UI.
- `NeutronAiPersonalModelLoader.Scope` requires exact live Minecraft account, world, player, connection, transport context epoch. `onScopeChange` and `withdraw` immediately revoke consent and dispose the model. `RotationManager` additionally checks the personal gate at the motion/AI PRE boundary and removes the model on reset/connection changes. A missing or invalid checkpoint is HOLD only, **never** automatic fallback to Adaptive, Arsenic or camera-only attack.
- The producer is offered through `ClientRuntime.getPersonalAiLoader` / `RuntimeServices.personalAiLoader()` to a future opt-in consent UI. Accessing this endpoint neither reads files nor grants consent. No automatic live training or user recording takes place in T4.
- **Important:** C03 transport admission, rotation ownership, existing raycast, attack scheduling, C02 and placement safety authority remain exclusively in the unchanged Aura/Minecraft pipeline. No modified attack/packet rules, anti-cheat claims or released weights.
